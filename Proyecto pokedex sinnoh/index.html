Acerca de

Aplicación web construida con Vanilla JS para visualizar datos de la Pokédex de Sinnoh. Este proyecto sirve como demostración de fundamentos web, incluyendo iteración de arrays, renderizado condicional de elementos y diseño adaptable (Mobile First).

Investigación y Recursos

Los datos se almacenan localmente en estructuras JSON optimizadas. La información combina la nostalgia de la Generación 4 con las mecánicas competitivas actuales (Gen 9), incorporando habilidades actualizadas.
